# Parte 2: El Grimorio del Mago – Dominando los Fundamentos de REST

Habiendo completado tu aprendizaje, ahora abres el grimorio del mago para dominar las artes fundamentales del diseño de APIs REST. Este tomo sagrado contiene el conocimiento esencial que te transforma de alguien que comprende las APIs conceptualmente en un profesional capacitado capaz de crear APIs REST elegantes y poderosas.

Dentro de estas páginas, estudiarás la antigua sabiduría de los diferentes estilos de APIs y aprenderás las artes adivinatorias necesarias para elegir el enfoque adecuado ante cualquier desafío mágico. Profundizaremos en las restricciones místicas y los modelos de madurez que gobiernan REST, yendo más allá de simples encantamientos para comprender los principios más profundos que hacen que una API sea verdaderamente RESTful. A través del estudio minucioso del modelado de dominios y la elaboración de contratos, aprenderás a entrelazar los requisitos de negocio en diseños de APIs robustos.

Este grimorio contiene los hechizos fundamentales, patrones y técnicas que los magos maestros de APIs utilizan para crear APIs mantenibles, escalables y fascinantes. Al dominar estas enseñanzas, poseerás las competencias centrales necesarias para diseñar APIs REST que sirvan tanto al ámbito técnico como al dominio de negocio con la misma elegancia.

Esta parte incluye los siguientes capítulos:

- **Capítulo 5**: Comparación y elección del estilo de API adecuado
- **Capítulo 6**: Restricciones de diseño REST y modelos de madurez
- **Capítulo 7**: Construcción de un modelo de dominio para el diseño de APIs
- **Capítulo 8**: Diseño y gestión de contratos de API efectivos
